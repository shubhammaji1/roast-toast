# The idea café

Three compositions considered before implementation:

1. **The editorial table (selected).** Warm paper, condensed sans headlines, italic serif punctuation, ruled feed posts and an orange ink stamp. Highest reading clarity, distinct character, compact social interface.
2. **The critique studio.** Cool white, monochrome grotesk and red margin annotations. Clear but less welcoming; annotations compete with discussion on small screens.
3. **The community noticeboard.** Brown paper, loose tiles and handwritten labels. Warm but less scalable for long discussions and keyboard order.

The selected system uses near-black ink, ivory paper, rust orange for roast actions, forest green for progress, and coffee brown for support. Four-pixel spacing, 4/8/12px radii, ruled sections. Display uses a condensed sans; reading uses a neutral sans; pull quotes use Georgia italic. No stock photos are needed: the product is the ideas and conversations.

Landing introduces the same live idea components as the feed. Desktop navigation is compact with a useful right-hand reading rail; mobile has its own bottom navigation. Dialogs use Radix focus management. Reduced-motion disables transitions. Demonstration identities, feedback and journeys are explicitly labeled throughout.

Core journey: browse → publish without an account → receive a structured roast → suggest an improvement → update the build journey. Coffee support is an optional external link to the creator’s Buy Me a Coffee page.
